# Meu Primeiro PR

Este repositório foi criado para praticar o fluxo de contribuição com Git e GitHub: criar uma branch, fazer uma alteração pequena e abrir um Pull Request.

## Sobre

Este é um repositório de aprendizado, criado com a ajuda do Claude Code.

## Como contribuir

1. Crie uma branch a partir da `main`
2. Faça sua alteração
3. Abra um Pull Request descrevendo o que mudou
